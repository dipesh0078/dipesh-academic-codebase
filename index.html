Nepali–English Code-Switched Speech Recognition

Ongoing

Nepali speakers switch between Nepali and English within a single sentence, often across two scripts (Devanagari and Latin). Most speech recognition systems are trained on one language and break at these switch points. This project builds the data foundation for studying that problem.

Data
An approximately 1,000-hour Nepali–English code-switched speech corpus from natural conversation and monologue content, with transcript alignment and word-level Nepali/English language tags.
Approach
Speech-to-text data preparation and evaluation pipelines for cross-script code-switching, with error analysis split by language and focused on switch boundaries.
Speech Recognition Code-Switching Low-Resource NLP

Multi-Organ Segmentation of Abdominal CT

2023–2024 · Undergraduate minor project

Radiologists outline organs slice by slice when planning treatment, which is slow work. This project trains 3D deep networks to label the liver, kidneys, spleen, and pancreas in abdominal CT volumes, and compares two architectures under the same pipeline.

Data
AbdomenCT-1K, stored as NIfTI volumes with uneven slice counts. Volumes were resampled with linear interpolation and label maps with nearest-neighbour interpolation, so organ labels never blend together.
Pipeline
A MONAI preprocessing chain: resample to 1.5 × 1.5 × 3.0 mm spacing, reorient to RAS, clip intensities to [−200, 200] HU and scale to [0, 1], crop to the foreground, resize to 128 × 128 × 64, and cache the dataset in memory for faster epochs.
Models
A 3D U-Net (5 levels, 16→256 channels, residual units, batch norm) and a SegResNet, both with 5 output classes (background plus 4 organs), trained for 200 epochs with Dice loss and Adam (lr 1e-4).
Deployment
A Flask web app that accepts a .nii.gz scan, resamples it, runs both trained models, and shows their segmentations side by side.
77.16% SegResNet test Dice  |  71.35% U-Net test Dice

Q-Learning Maze Agent

2026 · Python, Pygame

A reinforcement learning agent that learns to cross an 11 × 15 maze purely from rewards, with no path-finding algorithm or hard-coded route. Training is drawn live, so you can watch a random walker turn into one that heads straight for the goal.

How it works
A tabular Q-table stores the value of moving up, down, left, or right from each open cell. Rewards are +100 at the goal, −10 for hitting a wall, and −1 per step to favour short paths. Updates follow the Bellman equation (α = 0.1, γ = 0.9), with ε-greedy exploration decaying from 1.0 to 0.05.
Result
After training, the agent replays the greedy path read from the final Q-table. A headless mode prints the learned route in ASCII.

Micromouse Line-Maze Robot

2023 · Arduino C++

Firmware for an autonomous robot that explores a maze of black lines on a white floor, learns the route, and then runs it again along the shortest path.

How it works
Six analog IR sensors are calibrated at start-up to set per-sensor thresholds, and a PID controller keeps the robot on the line. On the dry run, each turn at an intersection is recorded as L, S, R, or B (left, straight, right, back), and dead-ends are removed as they happen (for example, "LBR" becomes "B"). The final run replays that shortened path.

Huffman File Compressor

2023 · JavaScript · Team project

A browser-based tool that compresses and decompresses text files losslessly using Huffman coding. It was built as a data structures and algorithms course project.

How it works
Character frequencies are counted and used to build a binary tree, so frequent characters get shorter bit codes. The encoded file keeps the tree, which lets the decompressor rebuild the exact original.
